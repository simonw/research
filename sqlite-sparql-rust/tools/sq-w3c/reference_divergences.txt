# Tests the REFERENCE backend (spareval 0.2.7 + spargebra 0.4.7) fails for reasons inside
# those crates, not in the harness. Each one was checked against the test's data, query and
# expected results. `sq-w3c --backend reference` treats this list as known failures (in
# addition to --known-failures), so a harness regression shows up as an unexpected failure.
# Format: one test IRI per line; '#' lines and anything after the IRI are comments.

# --- spargebra parser (these also affect sq-plan, which lowers spargebra's algebra) ---
# `OPTIONAL { { P FILTER(F) } }` is parsed as LeftJoin(_, P, F): the inner group is merged
# before filter scoping (the "simplified" reading; SPARQL 1.1 keeps the group, so ?title is
# unbound inside the FILTER and no price is ever joined).
http://www.w3.org/2001/sw/DataAccess/tests/data-r2/optional-filter/manifest#dawg-optional-filter-005-not-simplified

http://www.w3.org/2001/sw/DataAccess/tests/data-r2/expr-builtin/manifest#case-insensitive-booleans
